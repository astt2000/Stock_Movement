System Legend & Financial Metrics Specification Matrix
1 Price Threshold Parameters (SUP, RES, TGT)

• SUP (Support Level - 95% anchor): The price floor where buyer demand thickens to stall liquidation trends.

• RES (Resistance Level - 104% anchor): The price ceiling where supply clusters and traders lock in short-term returns.

• TGT (Target Level - 110% anchor): Technical target cycle milestone upon a successful volume-backed breakout.

EXAMPLE: If Nvidia (NVDA) trades at $100.00:
SUP = $95.00 (Stop-loss floor) | RES = $104.00 (Take-profit ceiling) | TGT = $110.00 (Breakout objective)
2 RSI-14 Index (Relative Strength Index)

Tracks actual directional acceleration vectors using a mathematical 14-day historical exponential close lookback:

• Value ≥ 65: Overextended channel footprint; technical probability favors profit-taking or cooling phases.

• Value ≤ 35: Heavily oversold; sell walls depleted, signaling potential value accumulation entry setups.

EXAMPLE: Stock jumps violently on earnings pushing the lookback index to 74. System notes overbought conditions, increasing reversion flags.
3 MACD Structural Phase (Moving Average Convergence Divergence)

Tracks standard cross-momentum changes using a 12-day vs 26-day EMA mathematical spread grid:

• Bullish Crossover / Momentum: Short-term momentum cross shifts above trailing trend averages, confirming upside velocity expansion rules.

• Bearish Realignment / Momentum: Trend vectors tilt downward through signal bands, establishing systematic distribution risk parameters.

EXAMPLE: A negative histogram flip triggers "Bearish Realignment", which shifts the system decision to SELL and drops confidence models.
